本文件按 [最小记录结构](../06-development-loop.md#1-最小记录结构) 归档阶段 B 期间已完成任务的历史验收记录。当前进度、待办任务与最近一轮记录见 [开发状态](../STATUS.md)。

## T023：HTTP 安全框架与只读 API（B-1）

- 目标与范围：完成 `B-1`，前置为阶段 A 全部完成（`A-6`）。新增 `internal/server` 路由与 HTTP 安全框架：仅绑定 `127.0.0.1`，每次启动生成 32 字节随机 Session Token 并校验 `X-Memctl-Token`，按实际监听端口校验 `Host`（`127.0.0.1`/`localhost`）并拒绝跨源或 `null` 的 `Origin`，返回 `Cache-Control: no-store`、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer` 与 `frame-ancestors 'none'` CSP，`--readonly` 中间件在路由前拒绝全部非 GET/HEAD 请求；注册 `GET /api/v1/snapshot`、`GET /api/v1/files/{path...}`、`GET /api/v1/entries`、`GET /api/v1/audit`、`GET /api/v1/doctor`、`GET /api/v1/conflict`；新增 `internal/app` 只读查询（快照与图谱、条目分页、审计分页、冲突状态）与 `internal/git.Log`、`internal/vault` 修订与时间辅助。`memctl ui` CLI 命令、内嵌前端与 SSE 属 `B-2`/`B-3`，本轮不实现。
- 契约：[HTTP 安全](../04-ui-and-cli-specification.md#5-http-安全)、[REST 契约](../02-domain-models-and-contracts.md#4-rest-契约)、[记忆快照与图谱](../02-domain-models-and-contracts.md#21-记忆快照)、[审计、诊断、整理与接入](../02-domain-models-and-contracts.md#23-审计诊断整理与接入)、[模块职责与目录规划](../01-architecture-and-modules.md#4-模块职责)、[文件与路径边界](../01-architecture-and-modules.md#32-文件边界)、[阶段步骤的子任务切分](../05-validation-and-delivery.md#阶段步骤的子任务切分)。
- 验证日期与环境：2026-10-16，macOS 26.6.2 arm64，Go 1.27.1，Git 2.54.0；执行者为主会话。
- 命令与结果：`go vet ./...`、`go test ./... -count=1`、`make build` 全部通过；测试使用临时 HOME 与临时记忆仓库、直接调用应用服务与处理器，不访问网络或真实凭据。`A01` 由 `TestB1RoutesCoversA01` 覆盖（六条只读路由注册、`{path...}` 取嵌套路径、错误方法返回 405 与 `Allow: GET`、未知路径 404、生成 Token 为 64 位十六进制）。`A02` 由 `TestB1AuthCoversA02` 覆盖（缺失/错误 Token 为 401 `AUTH_REQUIRED`，`null` 与跨源 `Origin` 为 403 `ORIGIN_DENIED`，伪造 `Host` 为 400，同源成功，`PATCH` 伪装读取返回 405，安全响应头齐全）。`A03` 由 `TestB1ReadOnlyCoversA03` 覆盖（只读模式对 POST/PUT/PATCH/DELETE 及 `sync`/`doctor:fix`/`dream:preview` 返回 403 `READ_ONLY`，GET 可用）。`P01`/`P02` 由 `TestB1PathBoundaryCoversP01P02` 覆盖（`%2e%2e%2f`、空段、`.git`、盘符路径返回 400 `INVALID_PATH`，符号链接返回 422 `UNSUPPORTED`）。`P03` 由 `TestB1LimitsCoversP03` 覆盖（`limit=201` 返回 413 `LIMIT_EXCEEDED`，非数字与负偏移返回 400，超过 2 MiB 的文本读取返回 413）。`TestB1SnapshotContent` 校验快照字段、孤立文件告警、`q`/`agent` 过滤与审计提交；`TestB1LoopbackListenerServesRealRequests` 经真实 TCP 环回端口验证 Host 与实际监听端口匹配。单元测试 `TestSplitAddrLoopbackOnly`、`TestListenBindsLoopbackOnly`、`TestValidateRequestPath`、`TestGenerateTokenIs32Bytes` 覆盖非环回地址拒绝、路径段拒绝与 Token 长度。
- 未验证与遗留：`memctl ui` 命令、内嵌前端与首页 meta Token 注入属 `B-3`，SSE 与文件监听属 `B-2`；仅在 macOS arm64 实机运行，Windows/Linux 的监听、路径与符号链接语义未运行；并发生成任务限额在 B 阶段无对应写接口，未验证；`snapshot` 在保护态返回 BUSY，未缓存最近完整快照，因此 `stale` 恒为 `false`。

## T024：文件监听与 SSE 状态流（B-2）

- 目标与范围：完成 `B-2`，前置为 `B-1`（`T023`）。新增 `internal/watcher`：基于 `fsnotify` 的递归目录监听、新建目录登记、rename/remove/原子替换处理、监听后端错误降级、150ms 防抖合并，以及 `Bus` 有界扇出（每个订阅者独立有界队列，溢出合并为一次 `resync.required`）；`internal/app` 新增 `MutationObserver` 插槽，本地写事务提交后主动发布失效提示；`internal/server` 注册 `GET /api/v1/events`，在安全中间件校验 `X-Memctl-Token` 后以 `text/event-stream` 推送 `vault.updated` 与 `resync.required`、发送评论心跳，并提供 `Server.Events` 与 `Server.Watch` 接线。`memctl ui` 命令、首页 meta Token 注入、内嵌前端与浏览器端 fetch 流解析/断线重连校正属 `B-3`；本轮以 Go 测试客户端验证跨块拆分、多行 `data` 与重连全量校正。`sync.status`、`sync.conflict`、`dream.updated` 的发布者属后续阶段，本轮不产生。
- 契约：[SSE 与缓存](../02-domain-models-and-contracts.md#5-sse-与缓存)、[HTTP 安全](../04-ui-and-cli-specification.md#5-http-安全)、[模块职责](../01-architecture-and-modules.md#4-模块职责)、[技术依赖](../01-architecture-and-modules.md#技术依赖)、[阶段步骤的子任务切分](../05-validation-and-delivery.md#阶段步骤的子任务切分)。
- 验证日期与环境：2026-10-16，macOS 26.6.2 arm64，Go 1.27.1，Git 2.54.0；执行者为主会话。
- 命令与结果：`go vet ./...`、`go test ./... -count=1`、`make build` 全部通过；`internal/watcher` 与 `TestB2*` 用例另以 `-race` 复跑通过。测试使用临时 HOME、临时记忆仓库与临时环回端口，不访问网络或真实凭据。`A05` 由 `TestB2SSEDecoderHandlesSplitChunksAndMultilineDataCoversA05`（逐字节拆分与多行 `data` 合并）、`TestB2SSEStreamsCommittedWriteCoversA05`（受管写提交即推送 `vault.updated` 且携带新 `revision`）、`TestB2WatchStreamsExternalEditCoversA05`（外部直接编辑经 `Server.Watch` 到达开放流）、`TestB2SSEResyncAndReconnectCorrectionCoversA05`（断开期间提交后重连以 snapshot 全量校正，并收到 `resync.required`）、`TestB2SSEHeartbeatCoversA05`（评论心跳）覆盖；队列溢出降级由 `TestBusBoundedQueueSignalsResync` 直接验证；递归登记与 rename/remove/原子替换由 `TestWatcherRecursivelyRegistersNewDirectories`、`TestWatcherCoversRenameRemoveAndAtomicReplace` 覆盖，防抖合并由 `TestWatcherDebouncesBursts` 覆盖，`.git` 排除由 `TestWatcherExcludesGitInternal` 覆盖。`A02` 的 SSE 鉴权由 `TestB2SSEAuthCoversA02` 覆盖（缺失/错误 Token 为 401 `AUTH_REQUIRED`，`null` 与跨源 `Origin` 为 403 `ORIGIN_DENIED`）。
