## T023：HTTP 安全框架与只读 API（B-1）

- 目标与范围：完成 `B-1`，前置为阶段 A 全部完成（`A-6`）。新增 `internal/server` 路由与 HTTP 安全框架：仅绑定 `127.0.0.1`，每次启动生成 32 字节随机 Session Token 并校验 `X-Memctl-Token`，按实际监听端口校验 `Host`（`127.0.0.1`/`localhost`）并拒绝跨源或 `null` 的 `Origin`，返回 `Cache-Control: no-store`、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer` 与 `frame-ancestors 'none'` CSP，`--readonly` 中间件在路由前拒绝全部非 GET/HEAD 请求；注册 `GET /api/v1/snapshot`、`GET /api/v1/files/{path...}`、`GET /api/v1/entries`、`GET /api/v1/audit`、`GET /api/v1/doctor`、`GET /api/v1/conflict`；新增 `internal/app` 只读查询（快照与图谱、条目分页、审计分页、冲突状态）与 `internal/git.Log`、`internal/vault` 修订与时间辅助。`memctl ui` CLI 命令、内嵌前端与 SSE 属 `B-2`/`B-3`，本轮不实现。
