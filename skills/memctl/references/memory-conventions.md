# 记忆内容规范

## 保存范围

- 跨会话仍然成立的事实：用户偏好、人物与项目、命名约定、环境约束、已解决的问题和可复用步骤。
- 保存前确认它不是临时状态。一次性任务进度、当前分支、临时路径与本次会话的中间结论不保存。
- 涉及第三方个人信息或无法判断是否敏感时，先询问用户。

## 禁止保存

- 密钥、令牌、密码、私钥、cookie，以及连接串中的凭据。
- 原始日志、大段构建输出、完整对话记录。
- 用户明确要求删除或不要保留的内容。

## 条目格式与三要素写法

- 顶层一行一条 bullet：`- <事实> [source: <tag>; added: YYYY-MM-DD]`（可附加可选 `; until: YYYY-MM-DD; kind: state|event|procedural; status: verified|hypothesis`）。
- 工程规则与排障记忆遵循三要素结构：**「结论/规则 + 实测验证依据（具体命令、探针输出或代码行）+ 常见陷阱警告」**，使后续会话既知道怎么做，也知道为什么成立以及避免踩什么坑。
- 顶层事实写成可独立理解的单句，不换行，不以「见上」等指代承接上下文；多步排障步骤、编号说明或代码围栏（```` ``` ````）紧跟在顶层 bullet 下方，以至少 2 个空格（`"  "`）或 1 个 Tab 缩进写成附属子块（`DetailLines`，上限 `20` 行且不超过 `2 KiB`）。附属子块会被 `entries --q` 检索，并在单条删除或跨文件移动时随顶层行整块处理。
- `source` 使用上下文给出的来源标签 `agent://<device>/<agent>/<sid>`；没有标签时省略或询问用户，不编造。
- `added` 记录学到该事实的日期，格式 `YYYY-MM-DD`。
- `kind`（可选，缺省按 `state` 处理）：`state` 表示当前状态或偏好（失效时就地改写或删除）；`procedural` 表示操作步骤或排障配方；`event` 表示历史决策、发布或事故（只追加不删改，代码级由 `EVENT_PROTECTED` 守卫拦截静默删改）。
- `status`（可选，缺省按 `verified` 处理）：已复现确认的事实用 `verified`；当前会话首次观察到、尚待跨会话复核的推测标 `hypothesis`（`doctor` 与 `dream --prepare` 会以 `UNCONFIRMED_HYPOTHESIS` 提醒后续复核）。
- 元数据值中若包含字面量分号 `;`，使用 `\;` 转义或用双引号 `"..."` 包裹整个值。
- 同一行可以有多个 `[source: ...]`，分别保留；不合并、不重排。
- 保留已有条目的未知元数据与顺序，不整段重排文件。

## 文件与链接

- `MEMORY.md` 是入口与索引，只放索引与跨项目偏好。项目决策、事件与主题事实写入 `notes/<topic>.md`（单文件建议控制在 `150` 行 / `16 KiB` 以内，超出时 `doctor` 报告 `TOPIC_BLOAT`）；每个新建文件在索引中增加一行 `[[path]]` 与简短说明。
- 链接使用仓库根相对路径；Markdown 文件省略 `.md`，其他资产保留扩展名。
- 一个事实只写一处。其他文件链接过去，不复制正文（跨条目词项重合度过高时 `doctor` 报告 `NEAR_DUPLICATE`）。链接目标可以是任意受管文件：主题文件之间同样互链，不是只能从 `MEMORY.md` 指向主题文件。
- 有时效的事实（试用期、临时约束、截止日期）在元数据末尾加 `until: YYYY-MM-DD`。该日过后顶层条目及其 `DetailLines` 子块会从注入与所有读取入口隐藏，文件与 Git 历史保留；不要自行删除被隐藏的条目。
- 旧条目失效时按事实类型处理，不追加矛盾条目：
  - 状态型（`kind: state`）与操作步骤型（`kind: procedural`）就地改写或删除，旧值不另存一条。
  - 事件型（`kind: event`：为什么这样选、发布、事故、迁移）追加一条带 `added` 与 `kind: event` 的新条目，旧条目原样保留且受 `EVENT_PROTECTED` 代码守卫保护；决策后来被推翻不是错误，不回改旧条目。
- 记忆文件内不维护变更记录，不写「以前是 X，现在是 Y」；历史版本由 Git 保存。
- 保持文件原有标题层级、换行与末尾状态；不做无关的格式化、空格调整或排序。

## 写入前检查

- 读取目标文件与 `MEMORY.md`，确认同一事实没有别处记录。
- 确认修改后的内容仍是单行 bullet，引用的链接目标存在。
- 新增文件后确认 `MEMORY.md` 索引已更新。
- 事实与来源可复核；不把推测写成确定结论。
